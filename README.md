# 🏦 Bank Loan Analysis Dashboard

An interactive Bank Loan Analysis Dashboard built using Python, Pandas, Plotly and Streamlit.

## 📊 Project Overview

This dashboard analyzes 70,000 loan applications and provides insights into loan approval status, credit scores, loan purposes, employment experience, income and loan amounts.

## 🚀 Features

- Total Loan Applications
- Approved and Rejected Loans
- Loan Approval Rate
- Total Loan Amount
- Average Loan Amount
- Loan Status Distribution
- Loan Status by Employment Experience
- Approval Rate by Credit Score Range
- Loan Amount by Loan Purpose
- Average Loan Amount by Employment Experience
- Loan Amount vs Annual Income
- Interactive Filters
- Recent Loan Applications Table

## 🛠️ Technologies Used

- Python
- Pandas
- Plotly
- Streamlit

## 📁 Dataset

The project uses a loan approval dataset containing 70,000 records and multiple customer and loan-related attributes.
